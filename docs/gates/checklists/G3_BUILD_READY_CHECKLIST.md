# G3 — Build Ready Checklist (Template)

## Entry criteria
- [ ] Scope + success metrics unchanged (or approved changes logged)
- [ ] Critical suppliers confirmed build dates + shipping
- [ ] Facility readiness minimum met (power/network/EHS)

## Checklist
### Hardware
- [ ] BOM at Rev: <X>
- [ ] Drawings released: <X%>
- [ ] Long-lead parts received: <list>
- [ ] Torque/calibration plan ready

### Controls / Software
- [ ] Release lock candidate identified (PLC/firmware/HMI versions)
- [ ] Safety interlock logic reviewed
- [ ] IO map baseline complete

### Facilities
- [ ] Power capacity verified
- [ ] CDA/exhaust/chilled water (if applicable) ready
- [ ] Network drops + VLAN approvals done
- [ ] Permits & EHS training complete

## Exit criteria / evidence
- [ ] Readiness review signed off by HW/Controls/Facilities/EHS
- [ ] “No critical blockers” in RAID (or explicitly accepted)
