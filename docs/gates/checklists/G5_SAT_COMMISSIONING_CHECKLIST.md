# G5 — SAT / Commissioning Checklist (Template)

## Safety first
- [ ] LOTO plan reviewed
- [ ] Safety interlocks verified (door, E-stop, light curtain, pressure relief)
- [ ] EHS signoff obtained

## Commissioning steps (example)
- [ ] Utility hook-up verified (power, network, CDA, exhaust)
- [ ] Power-on self test passed
- [ ] IO validation complete (inputs/outputs)
- [ ] Motion/actuator sanity checks
- [ ] Alarm taxonomy validated
- [ ] Basic functional run at low-risk settings

## Acceptance criteria
- [ ] No Severity-1 safety issues
- [ ] Key subsystems operate within spec
- [ ] Open issues have owners + due dates + containment plan
